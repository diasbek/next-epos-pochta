# Google Search — watch phrases (RU + UZ)

Список для мониторинга **Google Search Console → Performance** (фильтр по запросу)
и ручных SERP-снимков Google.uz.

Канон кластеров / URL: `WORDSTAT_CLUSTERS` / `SEO_SERP_MATRIX` в `goals.ts`.
Ops: `SEO_GOOGLE_BEHAVIOR` в `google-behavior.ts`.

Файлы:

- `google-watch-phrases.txt` — одна фраза на строку
- `google-serp-baseline.tsv` — шаблон позиций (заполнять вне репо или коммитить снимки)
- `google-keyword-layer.md` — как собирать Google volume hints

Приоритет: **RU на Google.uz** + бренд / навигационный UZ. Кластер → URL не менять без данных GSC.
